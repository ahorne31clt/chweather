## HRRR upgrade — October 30, 2026

The sunset generator now uses native 3-km HRRR cloud/visibility fields instead of GFS. Only extended 00/06/12/18 UTC cycles are accepted; hourly inputs must bracket every CONUS sunset within 48 hours. There is no shorter-cycle or GFS fallback.

Files added:
- `sunset/hrrr.py`: bounded filtered downloads, validated native Lambert fields, extended-cycle selection, native-grid scoring with sunward rays and chunked interpolation.
- `generated/sunset/lookup.bin.gz`: compressed high-resolution location lookup, generated by the command.

Files replaced:
- `sunset/__main__.py`: select HRRR, record 3-km/hourly/48-hour metadata, publish compressed lookup.
- `sunset/model.py`: algorithm version 2.0.0 and rankings on 2-D native coordinates; scoring weights unchanged.
- `sunset/render.py`: native-grid contours and HRRR source labels.
- `sunset/index.html`, `index.html`, `assets/sunset.js`: HRRR source/methodology/metadata labels.
- `assets/sunset-search.js`: SHA-checked compressed lookup and HRRR location results.
- `scripts/package_site.py`: include the binary lookup in the static export.
- `tests/test_sunset.py`: pipeline failure regression tests, extended-cycle horizon and next-UTC-day sunset checks.
- `.github/workflows/sunset.yml`: identify the HRRR sunset generation step; the same `python -m sunset` command remains scheduled at 8 a.m. Eastern.
- `README.md`, `docs/SUNSET.md`, this change log: updated model, operation, and exact upload details.
- `generated/sunset/latest.png`, `generated/sunset/latest.json`, `generated/sunset/lookup.json`: regenerated real HRRR outlook and lookup metadata.
- `output/ch-weather-github-ready.zip`, `output/ch-weather-website.zip`: refreshed source and static-site packages.
